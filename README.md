# Terminal-inspired academic website

Open `index.html` locally to preview. Upload all files to the root of your GitHub Pages repository when ready.

- **Publications:** Edit `posts.js`. Add a figure filename and summary to a publication record; figures belong in `figures/`.
- **Resource catalog:** Edit `resources.js` to add names, categories, descriptions, URLs, and two-letter icons. Search and category filters work without a server.
- **Featured sidebar figure:** Replace the placeholder in `index.html` with `<img src="figures/featured.jpg" alt="Description of figure">` after you supply the image.
- **About:** Edit `about.html`.
- **CV:** Edit `cv.html` after adding your PDF.

No framework, build step, or dependencies.
