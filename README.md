
# Terminal-Inspired Academic Website

A minimalist, terminal-inspired academic website built with HTML, CSS, and JavaScript and hosted on GitHub Pages.

Created by Sherlynette Pérez Castro to share research publications, an interactive scientific trajectory, and a curated collection of research resources.

**Live website:** https://sherlynettec.github.io/

## Features

- **Research publications:** Publication cards with figures, captions, and DOI links.
- **Interactive research trajectory:** A clickable visualization of research institutions and associated scientific outputs.
- **Scientific resources:** A searchable catalog of databases, bioinformatics tools, scientific references, and visualization resources.
- **Responsive design:** Layouts for desktop and mobile devices.
- **Lightweight architecture:** No frameworks, build tools, or external JavaScript dependencies.

## Customize Your Website

1. Fork this repository or download the source files.
2. Edit `index.html` to update your name, navigation, and homepage.
3. Edit `posts.js` to add your publications, figures, captions, and DOI links.
4. Edit `about.html` to customize your research introduction, institutions, and interactive trajectory.
5. Edit `resources.js` to add scientific tools, databases, and reference materials.
6. Edit `resources.html` to customize the resource categories.
7. Edit `style.css` to change colors, fonts, and layout.
8. Replace `cv.pdf` with your own academic CV.

## Publish with GitHub Pages

1. Create a GitHub repository named `YOUR-USERNAME.github.io`.
2. Upload the website files to the repository.
3. Under **Settings → Pages**, select deployment from your main branch and root directory.
4. Visit `https://YOUR-USERNAME.github.io/` once GitHub Pages finishes publishing.
